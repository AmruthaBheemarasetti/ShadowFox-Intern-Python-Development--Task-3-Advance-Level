# ShadowFox-Intern-Python-Development--Task-3-Advance-Level
This project performs a detailed fielding performance analysis for three players from any T20 match innings. It measures individual contributions using a Performance Score (PS) formula based on actions like clean picks, good throws, catches, stumping, direct hits, run outs, and runs saved/conceded.
# Task 3 – Cricket Fielding Analysis

## Objective
To analyze the fielding performance of three players from a T20 match using structured fielding data and performance metrics.

## Dataset
The dataset contains ball-by-ball fielding events including player actions, runs saved or conceded, and fielding outcomes.

## Methodology
Fielding actions were categorized into clean picks, catches, run-outs, missed chances, and direct hits. Each action was assigned a weight to calculate a Performance Score (PS).

## Performance Formula
PS = (CP×1) + (GT×2) + (C×3) + (DC×−2) + (ST×3) + (RO×4) + (MRO×−3) + (DH×4) + RS

## Results
Ravindra Jadeja recorded the highest performance score, followed by Hardik Pandya. Virat Kohli showed consistent fielding but had scope for improvement.

## Conclusion
This analysis helps identify strong fielders and areas of improvement, contributing to better defensive strategies in cricket.
